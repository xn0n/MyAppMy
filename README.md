# MyApp — алгоритмы в Windows Forms

**Учебные задания C++ с интерактивным интерфейсом.**

Desktop-приложение на C++/CLI для экспериментов с массивами, сортировками, рекурсией, графикой и объектами. Меню объединяет задания по семестрам и открывает вспомогательные формы ввода и визуализации.

`C++/CLI` · `Windows Forms` · `.NET Framework 4.7.2` · `Visual Studio 2022`

## Содержание

| Модуль | Учебная задача |
| --- | --- |
| `MyForm.h` | Главное окно, меню и обработчики, включая сортировку выбором, пузырьком и быструю сортировку |
| `Recursion.cpp` | Рекурсия и построение графиков |
| `Classes.cpp` | Иерархии геометрических объектов и управление ими |
| `Figures.h`, `Figures.cpp` | Форма отображения фигур |
| `Lab.cpp`, `Labirint.cpp` | Лабиринт и варианты его представления |
| `Input.h`, `MyFormInput.h` | Вспомогательные формы ввода |
| `Header.h`, `MyFunction.h` | Общие подключения и вспомогательные функции |

Некоторые части остаются заготовками: например, `Sort.cpp` пуст, а обработчики сортировки находятся непосредственно в главной форме. Описание относится к содержимому исходников, а не к подтверждённой приёмке всех пунктов меню.

## Сборка

Требуется Windows и **Visual Studio 2022**:

- Desktop development with C++;
- MSVC **v143**;
- поддержка **C++/CLI** для v143;
- Windows SDK 10;
- .NET Framework **4.7.2 Targeting Pack**.

Откройте `MyApp.sln`, выберите `Debug | x64`, соберите solution и запустите проект. В конфигурации также есть Win32 и Release.

```powershell
msbuild MyApp.sln /m /p:Configuration=Debug /p:Platform=x64
```

Команда предназначена для Developer PowerShell for Visual Studio с установленными компонентами выше.

## Особенности

Часть `.h` и `.cpp` использует **Windows-1251** для русских строк и идентификаторов. При публикации кодировка сохранена. Ресурсы форм хранятся в `.resx`; машинные настройки `.vcxproj.user` и результаты сборки не входят в репозиторий.

## Ограничения

Проект представляет учебные реализации и сохраняет историческую организацию кода. Он не заявляет промышленную обработку больших данных, криптографическую защиту или завершённость каждого демонстрационного задания.

Автоматизированные тесты в solution не определены. Сборка и ручные UI-сценарии при подготовке публичной копии не выполнялись; воспроизводимость нужно проверить в указанной Windows-среде.
